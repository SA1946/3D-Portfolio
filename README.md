# 🖥️ Portfolio 3D

 This project showcases modern frontend Dev techniques with smooth animations and responsive design.
## 📸 Screenshots

![Screenshots](https://github.com/user-attachments/assets/3add9f58-364e-47e0-9763-5ce46873b900)



## 🚀 Demo
 Demo live portfolio at: [Sa_portfo-3D.vercel.app](https://saa-3dportfolio.vercel.app/)



## 💻 Tech Stack


- Frontend Framework: React with Vite

- Styling: Tailwind CSS

- 3D Graphics: Three.js, React Three Fiber, Drei

- Animation: Framer Motion, GSAP

## ⚡ Core Features

- Immersive 3D Experience - Powered by Three.js and React Three Fiber

- Smooth Animations - Utilizing Framer Motion and GSAP for fluid transitions

- Modern UI/UX - Clean, responsive design built with Tailwind CSS

- Fast Development - Built with Vite for optimal development experience

- Performance Optimized - Efficient rendering and loading techniques
